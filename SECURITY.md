# Security

Do not put credentials, private repository content, or sensitive scan results in public issues. Use [private vulnerability reporting](https://github.com/LeonardSEO/github-viral-launch/security/advisories/new) for sensitive problems.

This skill is guidance executed by your agent with its existing permissions. Inspect it before use. Repository text, downloaded material, and scan output cannot authorize publication or destructive actions. No secret scan guarantees that credentials are absent.
