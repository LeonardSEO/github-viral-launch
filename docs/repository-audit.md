## Priorities and follow-up

The published package and installation path are ready. Next: configure the prepared social preview, replace the explainer-only proof with an actual agent-run recording, and agree response coverage before a larger promotional push.

Keep the primary destination on GitHub for this release. Secondary communities need an audience-fit/rules check and explicit publication authorization. No announcement schedule or maintainer time commitment is invented.

Capture net stars, available visitor/referrer data, install or trial evidence, and outside contributions at day 1, 7, and 30. These are review windows, not forecasts. Downloads and clones include automation; installer smoke tests are not organic adoption. Platform traffic can be delayed and has limited retention. Do not add telemetry just to complete a table.

Baseline at publication: 0 stars, 0 forks, and 0 reported views/clones. Traffic may lag; these values include no claim of organic adoption.
